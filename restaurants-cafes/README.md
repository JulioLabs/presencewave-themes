# Restaurant and Café Themes

Free, responsive website themes for restaurants and cafés: all-day cafés and brunch spots, family restaurants, street food stalls and food trucks, coffee roasters and tasting-menu restaurants. Every theme contains separate HTML, CSS, JavaScript, and any local assets it needs, and comes with something that turns a visitor into a guest: open-now hours and a filterable menu, a table request picker, a where-to-find-us schedule, a subscription builder and a private event estimator.

## Themes

- **Daybreak** — sunny landing page for cafés and brunch spots with an open-now badge and a menu filtered by vegetarian, vegan and gluten-free.
- **Trattoria** — warm multi-page theme for family restaurants with a table request picker by party size, day and time.
- **Night Market** — dark, neon landing page for street food and food trucks with a weekly schedule and a build-your-bowl calculator.
- **Pour Over** — minimal landing page for coffee roasters with this season's coffees and a subscription builder.
- **Supper Club** — elegant multi-page theme for tasting-menu restaurants with a private event estimator.
