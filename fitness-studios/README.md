# Fitness Studio Themes

Free, responsive website themes for fitness businesses: boutique class studios, yoga and pilates studios, strength gyms, personal trainers and community gyms. Every theme contains separate HTML, CSS, JavaScript, and any local assets it needs, and comes with a conversion path built for fitness: a class schedule with spots left, a pricing helper that shows the right plan, and a way to book a free class, pass, consult or tour.

## Themes

- **Afterburn** — bold, dark landing page for HIIT and cycle studios with a weekly schedule, spots-left badges and a free class form.
- **Stillpoint** — calm multi-page theme for yoga and pilates with a filterable timetable and a pack-or-membership planner.
- **Ironworks** — industrial landing page for strength gyms with a membership comparison and a free 3-day pass.
- **Personal Best** — clean landing page for personal trainers with a goal finder that recommends a program and price.
- **Neighborhood Gym** — friendly multi-page theme for community gyms with a family membership builder.
