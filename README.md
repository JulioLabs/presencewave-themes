# Presencewave Themes

Free, responsive website themes developed by [Presencewave](https://presencewave.com), organized by industry. Every theme is plain HTML, CSS and JavaScript: open `index.html` to preview it, and change the variables at the top of `css/styles.css` to apply your brand.

## Download links

Each theme is attached to the [latest release](https://github.com/JulioLabs/presencewave-themes/releases/latest) as `<industry>-<theme>.zip`, for example `lawn-care-fairway.zip`. The cleaning themes also keep their original names (`afterglow.zip` and so on), so older links keep working.
